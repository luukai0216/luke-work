# FORM / FX Studio

浏览器里的 3D 形状特效编辑器。导入模型，在粒子与 ASCII 字符之间切换，调整外观、旋转、形态动画和鼠标交互。

## 使用

1. 导入一个 GLB、OBJ 或 STL 文件，或选择内置形状。
2. 选择粒子或 ASCII，调整密度、大小、颜色、背景和透明度。
3. 选择自动旋转、呼吸、波动或漂浮，再配置鼠标排斥、吸引或跟随。
4. 点击「导出 JS」，下载包含点阵数据和渲染器的 `formfx-effect.js`，复制窗口中的 HTML 引用代码。

编辑器采用浅白背景和 #111111 黑色主题，无快速预设。

## 嵌入网页

将 JS 与 HTML 放在同一个目录，在需要展示效果的位置放入：

```html
<div id="formfx-effect" style="width:100%; height:480px;"></div>
<script src="./formfx-effect.js" data-target="#formfx-effect" defer></script>
```

文件包含模型、外观和动效，无需安装额外库或联网加载模型。高度由容器决定，宽度自动适应；多个效果使用不同的容器 ID。导出效果自动播放。

每个 script 标签提供 `formfx.pause()`、`formfx.play()` 和 `formfx.destroy()` 控制方法。效果不添加全局 CSS，移除时释放画布和资源。

拖动画布旋转视角，滚轮缩放。聚焦画布后按空格可暂停或播放。参数不自动保存，刷新页面会恢复默认值；请在离开前导出所需效果。

## 模型限制

- 模型始终在浏览器本地处理，不发送到服务器。
- 单个文件不超过 50 MB，三角面不超过 200 万。
- GLB 使用 glTF 2.0；此版本不支持 Draco / Meshopt 压缩。请导出未压缩 GLB。
- 忽略材质和贴图，只使用网格形状；多网格的世界变换会保留，再整体居中缩放。
- 使用模型导入时的网格姿态，不播放模型自带的骨骼动画。
- ASCII 是分布在 3D 表面上的字符点阵。

## 开发

`npm install`，然后运行 `npm run build` 与 `npm run dev`。默认预览地址为 http://127.0.0.1:4178。

渲染器使用 Three.js。`src/main.js` 是源代码，`dist` 是可发布的静态输出。
