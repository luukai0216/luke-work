追逐限价单竞品分析

对照 OKX、Gate、币安同一条路径。前两家是持续跟随的订单类型；币安是在已有挂单上点一次 Chase，改到买一 / 卖一。依据官方教程，未真实下单。

对照OKX · Gate · 币安
资料2026.09.20 · 官方帮助页
机制持续跟随 / 点一次追价
有截图 仅文字
概览

挂单价跟着盘口改，直到成交、撤单或触线。

OKX / Gate：下单后系统持续改价。币安：先下一张普通限价，再在委托列表点 Chase，只改这一次。

跟随

买跟买一，卖跟卖一

OKX 还可以设价差。Gate 默认贴盘口一价，约每秒改一次。币安确认后改到当前买一 / 卖一。

边界

最多追到哪

OKX / Gate 可设最大追逐距离，碰到就撤剩余。币安没有这条停止线。

约束

只挂单，下单后不能改

OKX / Gate 改距离只能撤了重下。币安用 Chase 改价、Cancel 撤剩余，撤单不等于平仓。

  1. 01
    选订单类型

    OKX / Gate 从限价旁边选出追逐限价。币安没有这个类型，入口在当前委托的 Chase。

  2. 02
    设规则

    数量、跟谁、追多远。距离要能换成具体价格。币安没有这些参数。

  3. 03
    确认

    核对跟随谁、停止线、只挂单。币安核对的是：这次会改到买一还是卖一。

  4. 04
    看当前委托

    还在追、现在挂在哪个价。币安改完后仍是普通限价，Chase 还在旁边。

  5. 05
    部分成交

    已成交留下，剩余继续跟。进度写成 8/100 比只写「部分成交」清楚。

  6. 06
    手动撤单

    撤的是未成交部分。已成交仓位还在。

  7. 07
    碰到停止线

    买到最高追逐价、或卖到最低追逐价，系统停改价并撤剩余。币安没有这一步。

  8. 08
    查历史

    结束原因、成交均价、跟随方式、停止线。原因要能分清：全成、手撤、触线。

结束 A · 全部成交

总量成交完，追逐结束。

结束 B · 手动撤销

剩余撤销，已成交保留。

结束 C · 触线终止

达到最大追逐距离，系统撤剩余。币安无此路径。

OKX

规则讲得清

入口有一句话，距离能换成具体价格。后半段教程薄。

Gate

任务管得全

独立筛选、分数进度、详情字段。入口和追踪委托撞名。

币安

挂单旁一键追价

Chase 贴着未成交单。改一次就停，没有持续跟随、也没有停止线。

逐步对照

同一步，三家各做了什么。

绿色 = 官方教程有截图。蓝色 = 只有文字。

01 发现

入口放哪，怎么解释。

OKX · App
官方截图
  • 高级委托组：追逐限价、高级限价、移动止盈止损、计划委托
  • 副文案：委托价按买一或卖一自动调整
Gate · App
官方截图
  • 高级组里，追踪委托和追逐限价单挨着
  • 副文案：追逐盘口自动更新
币安 · App
官方截图
  • 不是新的订单类型。入口在 Open Orders，普通限价旁有 Chase
  • U 本位合约可用；Portfolio Margin 不可用
02 设置

跟谁、买多少、追多远。

OKX · App
官方截图
  • 追逐方式：买一／卖一，或买一/卖一距离
  • 最大追逐距离是勾选项，弹层算出最高买价 / 最低卖价
Gate · App
官方截图
  • 默认盘口最优价；样本可见追逐间隔每秒
  • 最大追逐距离在高级选项，可切 %，并显示最高追逐价
币安 · App
规则
买单 → 当前买一
卖单 → 当前卖一
  • 没有跟随方式、价差、最大距离
  • 不套用 OKX / Gate 的参数表
03 确认

这次改的是什么价。

OKX · App
仅文字
官方要求二次确认。
教程没给弹层截图。
  • 写明：不能改价格、数量、最大追逐距离
  • 始终 post-only
Gate · App
官方截图
  • 列出合约、方向、数量、买1价、只挂单
  • 弹层里没有最高追逐价 / 停止线
币安 · App
官方截图
  • 写明：买单改到 bid1，卖单改到 ask1
  • 可勾选不再提示。样本没显示具体目标价
04 运行中

还在追吗，挂在哪。

OKX · App
官方截图
  • 混在「委托」列表
  • 价格写成「委托价格（追逐）」
Gate · App
官方截图
  • 可筛「追逐限价单」；标签写开多 + 追逐限价单
  • 样本里的追逐价格写「买1价」，不是具体数字挂价
币安 · App
官方截图
  • 改完仍是 Limit，Chase 还在旁边，可以再点
  • 列表要回答：现在挂在哪。不要写成「追逐中」
05 部分成交

成交一部分，剩余还追。

OKX · App
官方截图
  • 能看出数量，样本成交量为零
  • 未见「追逐中 + 已成交 20%」的组合表达
Gate · App
官方截图
  • 截图：已成交 / 总数量 = 8/100 张
  • FAQ：未成交部分继续按最新盘口一价挂
币安 · App
官方截图
  • 卡片有 Filled / Amount，样本是 0.000 / 0.500
  • 教程没写部分成交后 Chase 作用在剩余还是总量
06 撤单

撤的是剩余，不是仓位。

OKX · App
官方截图
  • 下单后不能改，只能撤了重下
  • 有单笔和批量撤单
Gate · App
官方截图
  • 单笔撤单、全部撤单
  • 手动取消是三种终止之一
币安 · App
官方截图
  • Chase 改价，Cancel 撤单，两个按钮并排
  • 不要让用户把追价理解成撤单
07 触线

追太远，系统怎么停。

OKX · App
官方截图
  • 买一 80、最大距离 50：跟到 100；到 130 自动取消
  • 弹层同步显示最高买价 / 最低卖价
Gate · App
仅文字
买单：最新价 ≥ 最高追逐买价则终止。
未见触线结果页。
  • 历史状态写成「已终止」
  • 规则在 FAQ 和高级选项里
币安 · App
无此步骤
点一次 Chase，改完就是普通限价。
没有停止线。
  • 保护靠确认层，不靠最大追逐距离
08 复盘

为什么停、成交多少、均价多少。

OKX · App
仅文字
教程停在当前委托。
历史详情未见。
  • 结束原因、改价记录、成交明细均未见
Gate · App
官方截图
  • 历史可筛追逐限价单；100/100 和 0/20 都写成「已终止」
  • App 教程最后一张是追踪止盈，不能当追逐单用
币安 · App
仅文字
教程没给历史页。
应能看到改前价 / 改后价。
  • 单次追价要回答：何时改了什么价。不要做成追逐策略档案
总结

前半段看 OKX，后半段看 Gate。币安看挂单旁的 Chase。

OKX

入口解释、追逐方式、距离换成具体价格。确认页、部分成交、结束原因，教程没给界面。

Gate

独立筛选、8/100 进度、运行中 / 已终止。入口和追踪委托撞名；确认页没写停止线。

币安

Chase 贴着未成交单，确认写清改到买一 / 卖一。这是改一次，不是一直追。

先让用户分清：改一次，还是一直追。 追踪 / 跟踪委托不要放进追逐限价的对照列。追踪是回调后触发新单；追逐是未成交挂单价跟着盘口改。
