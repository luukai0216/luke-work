使用与可读性

字号、行高、字重与行长需要协同工作。以下边界确保内容在品牌传播和产品界面中保持良好可读性。

  1. 产品正文至少使用 14px，默认采用 16px / 24px。
  2. 正文行高保持在字号的 1.4 至 1.6 倍。
  3. 连续正文每行建议控制在 45–75 个英文字符的等效长度。
  4. 全大写仅用于按钮、导航与简短状态标签。
  1. 产品界面中的正文字号不得低于 14px。
  2. 避免使用低于字号 1.2 倍或高于 1.8 倍的行高。
  3. 不要使用全大写或高字重排版长段落。
  4. 避免过长行宽、极端字距或正文居中排版。
