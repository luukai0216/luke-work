仿冒域名

同形字（如 tronIink / tronlink-app）、相似拼写、新增子域、HTTP 不带锁等手段诱导用户登录假站。

💡 识别：对比 tronlink.org 主域，检查浏览器锁标与 SSL 证书颁发对象。

📱

仿冒 App / 插件

非官方应用市场或第三方下载站提供修改版 APK / IPA，或仿冒插件 ID 上架到错误的扩展商店。

💡 识别：仅从 Google Play / App Store / Chrome Web Store / Edge Add-ons 安装；核对开发者 Helix Tech Company Limited。

🎭

假冒"官方客服"

私信、Telegram 群、邮件或评论区中自称 TronLink 客服，索取助记词、私钥或要求屏幕共享。

💡 识别：官方从不主动私信。客服仅通过 tronlink@tronlink.org 邮件或 Zendesk 工单回复。

🎁

假空投与"领取"诈骗

钱包内莫名出现的小额代币 / NFT，跳转的领取页要求"验证钱包"或签名陌生交易，往往是授权陷阱。

💡 识别：陌生空投不要互动；领取页要求签名前，先在 TronScan 检查合约地址。

📜

恶意 DApp 授权

钓鱼 DApp 诱导用户对恶意合约授予无限额度（unlimited approval），随后批量转走通证。

💡 识别：授权额度按需设置，定期通过 TronScan「授权管理」清理多余授权。

📋

地址污染（尾号攻击）

攻击者向你转 0 元小额，伪造与你常用收款地址首尾几位相同的地址，混入你的转账历史。

💡 识别：转账前完整核对地址，不要只看尾号；使用地址簿保存可信收款方。
