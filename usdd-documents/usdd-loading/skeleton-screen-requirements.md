# USDD 全站骨架屏设计需求

> 调研日期：2026-04-21（重新调研）  
> 调研工具：Playwright 全页截图（1920 桌面 + 390 移动双宽度）  
> 调研范围：usdd.io + app.usdd.io 全部页面

**触发条件：** JS 渲染完成后，数据尚未返回前（包括 API 请求和链上 RPC 读取）。静态内容随 JS bundle 加载，无等待状态，不需要骨架屏。

**标注说明**

- ✅ 已实现骨架屏，形态合理，统一骨架屏样式
- ⚠️ 有占位但不是骨架屏（显示 `...` / `0` / `--` / `No data` / 空行），统一为骨架屏样式
- ❌ 完全没有骨架屏，补充骨架屏样式
