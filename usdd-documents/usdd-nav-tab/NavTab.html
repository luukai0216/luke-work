NavTab

导航栏中的页签单元，支持纯文字与带下拉箭头两种布局，包含 Default、Hover、Active、Dropdown-Open 共四种交互状态。

States Overview
Variants
Default
未选中、未悬停的静止状态。文字白色，背景透明。
Hover
鼠标悬停时触发。文字变为品牌绿，背景浮起为 bg-elevated。
Active
当前页面对应的 Tab。文字品牌绿，背景透明，无需背景强调。
Default + Dropdown
含子菜单的 Tab，默认态。显示向下箭头，文字白色。
Dropdown Open
子菜单展开中。背景浮起，箭头反转向上，品牌绿文字。
Active + Dropdown
当前页面下的含子菜单 Tab，菜单关闭。品牌绿 + 向下箭头。

Do / Don't
✓ Do

同一行内只让 一个 Tab 处于 Active 状态，反映当前路由。其余保持 Default。

✕ Don't

不要让多个 Tab 同时显示 Active 状态，会造成用户对当前位置的混淆。

✓ Do

Dropdown 展开时，箭头向上 + bg-elevated 背景，明确告知用户当前面板已打开。

✕ Don't

不要给 NavTab 加描边或使用非规范颜色，会与 Button 组件产生混淆。NavTab 没有 border。
