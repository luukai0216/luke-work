# PSM 优化点梳理


| 模块  | 优化点                                                                                                                                   | 负责人  | 状态      |
| --- | ------------------------------------------------------------------------------------------------------------------------------------- | ---- | ------- |
| PSM | **流动性可用量数字过长** 视觉数字"552,309,822.6598 USDD"精度冗余，字号小，用户无法快速建立有效信息。→ 截短为"552.3M USDD"，hover 时展示完整精确数值。                                   | luke | 完成优化点梳理 |
| PSM | **缺少常用金额快捷按钮** 用户每次手动输入金额，操作摩擦高，尤其在移动端。→ 输入框增加 25 / 50 / 75% 快捷按钮，一键填入对应比例。                                                           | luke | 完成优化点梳理 |
| PSM | **Approve → Swap 缺少步骤提示** 当 Approve 成功后，2 步 modal 弹出，用户不清楚当前进行中。→ 在 Confirm modal 内增加步骤指示"Step 1/2: 授权"+"Step 2/2: Swap"。参考 spark 设计。 | luke | 完成优化点梳理 |
| PSM | **代币选择缺少互斥过滤** From 选择 USDT 时，To 的列表仍显示 USDT 选项，用户可能误选相同代币兑换。→ From/To 联动过滤：From=USDT 时 To 只显示 USDD，反之亦然。                             | luke | 完成优化点梳理 |
| PSM | **Toast 重复出现 Bug** 同一失败通知连续弹出 2 次，用户看到重复错误信息，影响对产品稳定性的信任感。→ 增加去重/防抖逻辑，同类 Toast 在 3s 内只触发一次。                                           | luke | 完成优化点梳理 |
| PSM | **错误文案过于技术化** "Transaction not found"不传达任何操作引导。→ 改为"交易提交失败，请稍后重试"，并附"查看详情"外链，降低用户困惑。                                                  | luke | 完成优化点梳理 |
