# Prompt：评审准备

## 使用场景

正式评审前，让 AI 预判可能被挑战的点并准备应答策略。

## Prompt 模板

```
请帮我准备 [功能名称] 的评审。

先读取 PRD：
- USDD2.0/iterations/v{x.y.z}/prd-{name}.md

本次评审参与者包括：
- [前端开发 / 后端开发 / QA / 设计师 / PM Lead]

请：
1. 根据每个参与者的角色，预判他们可能提出的 Top 3 问题
2. 为每个问题准备应答策略（数据支撑 / 替代方案 / 已考虑的理由）
3. 列出 PRD 中最薄弱的 3 个点（最可能被挑战的地方）
4. 建议评审时的展示顺序（先讲什么、后讲什么）

输出格式：
## [角色名]
### 可能提问 1：[问题]
**应答策略**：[准备的回答]

## PRD 薄弱点
1. [薄弱点] — 建议提前准备 [什么]
```

## 注意事项

- 评审准备是 AI 辅助，不是替代思考
- AI 预判的问题可能与实际不完全一致，但能帮你提前做好心理准备
- 建议将评审准备的输出快速过一遍，补充自己想到的问题
