## 三、功能详细 Spec

### F01: 导航栏展示与品牌标识

> **截图参考**：⚠️ 待补充
> **设计稿**：见 `figma-design-index.md`

#### 用户故事
> 作为**网站访客**，我希望在任意页面顶部看到 USDD 品牌标识并能点击回到产品主页，以便快速识别产品身份和进入核心应用。

#### 前置条件
- 用户已访问 usdd.io 任意页面

#### 主流程（Happy Path）
1. 用户打开 usdd.io 任意页面
2. 页面顶部显示**固定导航栏**，包含以下内容：
   - **左侧品牌区域**：USDD Logo 图标 + "USDD" 文字 + "Decentralized USD" 副标题
   - Logo 及文字区域可点击
3. 用户点击品牌区域
4. 系统在当前标签页跳转到 app.usdd.io

#### 分支流程与异常处理

| 场景编号 | 触发条件 | 系统行为 | UI 表现 |
|---------|---------|---------|--------|
| E01-01 | app.usdd.io 不可达 | 浏览器按默认行为处理 | 显示浏览器默认错误页 |
| E01-02 | 页面滚动 | 导航栏保持固定在视口顶部 | 导航栏不随页面滚动消失 |

#### 业务规则

| 规则编号 | 规则描述 | 校验时机 | 失败处理 |
|---------|---------|---------|---------|
| BR-G01 | 品牌 Logo 点击始终跳转至 app.usdd.io（非 usdd.io 首页） | 用户点击时 | 无特殊处理，走浏览器默认跳转 |
| BR-G02 | 导航栏在所有页面顶部固定显示，z-index 最高层 | 页面加载时 | — |

### F02: 导航链接与下拉菜单

> **截图参考**：⚠️ 待补充
> **设计稿**：见 `figma-design-index.md`

#### 用户故事
> 作为**网站访客**，我希望通过顶部导航快速访问各功能页面，以便高效获取所需信息。

#### 前置条件
- 用户已访问 usdd.io 任意页面
- 导航栏已加载完成

#### 主流程（Happy Path）
1. 用户查看导航栏中部，看到以下导航链接：
   - **Home**：直接链接
   - **Developer**：带下拉菜单标记（⚠️ 需确认：当前内容为空/404，是否展示该入口）
   - **Transparency**：带下拉菜单标记
   - **Community**：带下拉菜单标记
2. 用户鼠标悬停在 **Transparency** 上
3. 系统展开下拉菜单面板，包含以下子项：
   - **Data**：图标 + 标题 "Data" + 描述 "Real-time on-chain metrics" → 跳转 /data
   - **Smart Allocator**：图标 + 标题 "Smart Allocator" + 描述 "Yield strategy overview" → 跳转 /sa
   - **USDD Treasury**：图标 + 标题 "USDD Treasury" + 描述 "Reserve and treasury data" → 跳转 /treasury
4. 用户点击某个子项
5. 系统跳转到对应页面

**Community 下拉菜单子项：**
   - **News**：图标 + 标题 "News" + 描述 "Latest updates and announcements" → 跳转 /news
   - **FAQs**：图标 + 标题 "FAQs" + 描述 "Common questions answered" → 跳转 /faq

| E02-02 | 用户点击 Home 链接 | 跳转至首页 / | 页面刷新或路由切换到首页 |
| E02-03 | 用户点击 Developer 下拉 | ⚠️ 需确认：当前行为未定义（内容为空/404） | ⚠️ 需确认 |
| E02-04 | 用户在当前页面对应的导航项上悬停 | 下拉菜单正常展开，当前页面对应子项可能有高亮态 | ⚠️ 需确认：是否有 active 状态标记 |
| E02-05 | 移动端/触控设备访问 | ⚠️ 需确认：移动端导航交互方式（汉堡菜单？） | ⚠️ 需确认 |

## 四、模块级总览

### 4.1 页面流程

本模块为全局壳层，不独立构成页面，而是作为所有页面的公共结构。

**导航行为：**
- 用户访问 usdd.io 任意页面 → 顶部显示**固定导航栏**，底部显示**页脚**
  - 点击品牌 Logo → 跳转 app.usdd.io
  - 点击 Home → 跳转首页 /
  - 悬停 Transparency → 展开下拉菜单
    - 点击 Data → 跳转 /data
    - 点击 Smart Allocator → 跳转 /sa
    - 点击 USDD Treasury → 跳转 /treasury
  - 悬停 Community → 展开下拉菜单
    - 点击 News → 跳转 /news
    - 点击 FAQs → 跳转 /faq
  - 点击 Launch APP → 跳转 app.usdd.io

**页脚行为：**
- 点击 support@usdd.io → 打开邮件客户端
- 点击 X 图标 → 新标签页打开 twitter.com/usddio
- 点击 Discord 图标 → 新标签页打开 Discord 服务器

### 4.2 模块依赖关系

**本模块包含 3 个子模块：**

1. **导航栏（Navbar）**：顶部固定导航 — 提供品牌标识、页面导航、APP 入口
2. **页脚（Footer）**：底部全局页脚 — 提供品牌信息、联系方式、社交链接
3. **全局主题（Global Theme）**：视觉基础 — 定义背景色、字体、交互风格

**与其他模块的关系：**
- **所有官网页面模块**（homepage、data、smart-allocator、treasury、news、faq）：本模块作为壳层包裹所有页面内容，导航栏提供页面间跳转能力
- **app.usdd.io（外部）**：品牌 Logo 和 Launch APP 按钮跳转至外部应用站点，非本站路由

### 4.3 已知待优化项

| # | 描述 | 影响 | 建议优先级 |
|---|------|------|----------|
| 1 | Developer 菜单当前内容为空/404，但入口仍然展示 | 用户点击后看到空内容或 404 页面，体验割裂 | P1 |
| 2 | 移动端导航交互方式不明确 | 移动端用户可能无法正常使用 hover 下拉菜单 | P1 |
| 3 | 页脚 Discord 链接具体地址待确认 | 用户可能无法正确跳转至社区 | P1 |
| 4 | 版权年份硬编码为 2026，非动态获取 | 跨年后需手动更新，存在遗忘风险 | P3 |
| 5 | 导航栏无当前页面 active 状态标记 | 用户无法直观感知当前所在页面 | P2 |

### 4.4 迭代建议

| 优先级 | 建议 | 原因 |
|-------|------|------|
| P1 | 隐藏或标记 Developer 菜单为 "Coming Soon" | 避免用户点击后遇到空内容/404，影响产品专业度 |
| P1 | 补充移动端响应式导航方案（汉堡菜单等） | 移动端用户占比不可忽视，hover 交互在触控设备上不可用 |
| P2 | 为当前页面对应的导航项增加 active 高亮态 | 提升导航可用性，帮助用户定位当前位置 |
| P2 | 页脚增加官网内部页面的快捷链接 | 提升页面间可达性，SEO 友好 |
| P3 | 版权年份改为动态获取当前年份 | 减少人工维护成本 |
