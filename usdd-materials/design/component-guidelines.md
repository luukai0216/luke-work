# 组件指南

> UI 组件的标准使用规范。生成原型和走查时 AI 需参考此文件。

## 色彩 Token

| Token 名称 | 色值 | 用途 |
|-----------|------|------|
| `--color-primary` | [#XXXXXX] | 主操作按钮、链接 |
| `--color-secondary` | [#XXXXXX] | 次要操作 |
| `--color-success` | [#XXXXXX] | 成功状态 |
| `--color-warning` | [#XXXXXX] | 警告状态 |
| `--color-error` | [#XXXXXX] | 错误状态 |
| `--color-bg-primary` | [#XXXXXX] | 主背景 |
| `--color-bg-secondary` | [#XXXXXX] | 卡片背景 |
| `--color-text-primary` | [#XXXXXX] | 主文字 |
| `--color-text-secondary` | [#XXXXXX] | 次要文字 |

> **规则**：原型中禁止使用裸色值，必须引用 token。

| Body | [Npx] | [Npx] | Regular | 正文 |
| Caption | [Npx] | [Npx] | Regular | 辅助说明 |

| 字体族 | 适用场景 |

| [中文字体] | 中文文案 |
| [数字字体] | 金额、数量等数字展示 |
| [英文字体] | 英文文案 |
