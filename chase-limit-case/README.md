# 追逐限价单 · luke 的设计案例初稿

打开同目录的 `index.html` 即可使用。它是独立 HTML，不需要安装软件包，也不连接任何真实行情或交易账户。资料来源链接需要网络。

## 内容

- 问题定义、竞品依据和设计取舍。
- 买入／卖出规则的分步演示。
- 11 个移动端场景，可切换或展开全部页面查看。
- 从入口、参数、确认到部分成交、撤单、终止与详情的可操作原型。
- 状态表、UI 原则、可用性验证计划及 8 分钟面试讲述顺序。

## 建议演示

选择追逐限价 → 设置距离 → 确认下单 → 用手机右侧的演示按钮模拟部分成交 → 模拟触及边界 → 查看详情。

右侧“演示操作”不属于 APP 本身。场景标签用于查看固定示例，会重置数量和距离；需要保留自己输入的数据时，沿手机内按钮操作。

页面右上角提供浏览器打印入口，可自行选择存为 PDF。HTML 是完整可交互版本。

## 版本边界

这是面试作业的独立概念方案，并非 KuCoin 当前产品复刻。竞品规则引用官方资料；本方案的触发依据、基准和产品范围单独列为设计假设。还没有开展用户测试，不包含虚构效果数据。

主路径为开仓，包含买入和卖出方向。正式落地前仍需补齐平仓约束、真实平台参数范围、保证金与只挂单拒绝策略，并对照当前 APP 规范。

所有价格和数量均为演示值。原型数量输入范围为 0.01–0.10 BTC，步进 0.01；距离输入范围为 0.1%–5%，这些都不是实际平台限制。

## 已检查

- 内嵌 JavaScript 语法，以及浏览器运行期间的错误日志。
- 下单、部分成交后撤单、卖出方向触线终止、全部成交和详情路径。
- 错误输入保留、距离换算、连接异常和恢复。
- 320px、390px 的页面宽度与默认桌面显示，11 个场景总览。

手机软键盘、大字体与屏幕阅读器仍需真机测试。未实际导出并逐页审阅 PDF。
