# Skill: sync-drive

> 将项目文档同步到 Google Drive，同步前自动创建备份快照。

## 触发方式

```
"帮我同步到 Drive"
"同步文档到 Google Drive"
"sync drive"
```

## 执行流程

### 1. 确认同步范围

询问 PM 同步范围：

- **全量同步**：整个知识库（首次或季度同步时使用）
- **增量同步**：仅同步指定版本或变更文件（日常使用）

### 2. 创建备份快照（同步前自动执行）

> Google Drive 对非 Google 格式文件（.md / .html / .csv）的版本历史需要手动「保留此版本」才能下载旧版本，实际操作中容易遗漏。因此采用独立备份目录作为主要回滚手段。

```
Drive 目录结构：
[产品名] 知识库/
├── _backup/                          # 备份目录
│   ├── 20260315-PRD定稿.zip          # 全量打包快照
│   ├── 20260320-评审后修改.zip
│   └── 20260401-v4.9.0上线.zip
├── shared/                           # 当前最新版本
├── extension/
└── ...
```

**备份规则**：

| 规则 | 说明 |
|------|------|
| 备份命名 | `YYYYMMDD-{节点描述}.zip`，如 `20260315-PRD定稿.zip` |
| 备份内容 | 全量打包当前 Drive 中的完整知识库为一个 `.zip` 文件 |
| 备份保留 | 保留 90 天，超期由 PM 手动清理 |
| 必须备份的节点 | PRD 定稿后、评审修改后、版本上线基线合并后 |

> **为什么全量打包？** 差异备份回滚时需从多个目录拼凑文件，容易遗漏。全量 `.zip` 解压即可一步恢复到任意历史节点。`.md` / `.csv` 等文本文件压缩率高，空间开销很小。

**执行步骤**：

1. AI 询问本次备份节点描述（如「v4.9.0 PRD定稿」）
2. 将 Drive 中当前完整知识库打包为 `YYYYMMDD-{描述}.zip`
3. 存放到 Drive 的 `_backup/` 目录
4. 确认备份完成后，再执行同步覆盖

### 3. 执行同步

同步以下类型的文件到 Google Drive：

| 文件类型 | 是否同步 | 说明 |
|---------|---------|------|
| `.md` | ✅ 同步 | PRD、评审、模板等 |
| `.csv` | ✅ 同步 | 翻译、埋点 |
| `.html` | ✅ 同步 | 原型（文件可能较大） |
| `.png/.jpg` | ✅ 同步 | 截图 |
| `node_modules/` | ❌ 不同步 | |
| `.git/` | ❌ 不同步 | |
| `.DS_Store` | ❌ 不同步 | |
| `_backup/` | ❌ 不同步 | 备份目录仅存在于 Drive |

### 4. 输出同步报告

```markdown
## 同步报告
- 同步时间：[YYYY-MM-DD HH:MM]
- 同步范围：[全量/增量]
- 备份节点：[节点描述]
- 备份位置：_backup/[YYYYMMDD-描述]/
- 新增文件：[N] 个
- 更新文件：[N] 个
- Drive 目录：[Google Drive 路径]
```

## 回滚流程

当需要恢复到历史版本时：

1. 进入 Drive 的 `_backup/` 目录
2. 下载目标节点的 `.zip` 文件（如 `20260315-PRD定稿.zip`）
3. 解压后覆盖 Drive 主目录中的对应文件
4. 通知 PM 在本地也同步回退（从 Git 历史恢复）

> **注意**：本地 Git 是更精确的版本管理工具。Drive 备份用于团队成员自助回滚查阅，不替代 Git。

## 注意事项

- **必须由 PM 显式触发**，AI 不主动同步
- 同步前备份是强制步骤，不可跳过
- 敏感信息（密钥、内部数据）不应出现在同步文件中
- 首次同步时无需备份（Drive 上没有旧文件）

## 配置

在项目根目录的 `sync-config.json` 中配置：

```json
{
  "drive_folder_id": "[Google Drive 文件夹 ID]",
  "sync_paths": [
    "shared/",
    "USDD2.0/modules/",
    "USDD2.0/iterations/",
    "research/",
    "design/",
    "templates/"
  ],
  "exclude_patterns": [
    "node_modules/",
    ".git/",
    ".DS_Store",
    "_backup/"
  ],
  "backup": {
    "enabled": true,
    "retention_days": 90,
    "required_checkpoints": [
      "PRD 定稿后",
      "评审修改后",
      "版本上线基线合并后"
    ]
  }
}
```
