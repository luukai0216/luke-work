UI-KB · 设计规范工作流

从 Figma 设计稿到规范同步

覆盖「Figma 无规范」和「Figma 已有规范」两种路径，AI 自动处理部分已简化概括。

⚙
前置：确认 UI-KB 本地路径
每人 Google Drive 挂载路径不同，需先找到自己机器上的 UI-KB 目录绝对路径。
路径结构说明（macOS）
# 完整路径模板 /Users/{系统用户名}/Library/CloudStorage/ GoogleDrive-{Google邮箱}/ 共享云端硬盘/TRON-ECO-UI 组内/UI-KB/ # 示例（lucas.wang） /Users/wangyongxing/Library/CloudStorage/ GoogleDrive-lucas.wang@tron.network/ 共享云端硬盘/TRON-ECO-UI 组内/UI-KB/
a
系统用户名：终端输入 whoami
b
Drive 挂载名：终端输入 ls ~/Library/CloudStorage/，找到形如 GoogleDrive-yourname@tron.network 的目录
c
（最简方式）Finder 复制路径：前往 共享云端硬盘 → TRON-ECO-UI 组内 → UI-KB → 按住 ⌥ 右键 → 「将 "UI-KB" 拷贝为路径名称」
💡 路径含空格时用引号包裹，或使用 TRON-ECO-UI\ 组内 反斜杠转义。第一次使用后告知 Claude Code「记住这个路径」，后续无需重复填写。
1
判断 Figma 是否已有整理好的设计规范
查看对应项目的 Figma 文件，确认是否存在已整理完善的「设计规范」页面，包含色彩 Token、字体规格、组件规格和截图。根据结果选择下方对应路径。
🔍 Figma 是否存在整理好的设计规范文件？
✗ 无规范 — 先生成再同步
A1
发指令：引用 UI-KB 索引自动生成草稿 告知 Claude Code 该项目尚无规范文件，让它读取 UI-KB 中已有的 figma-index.md，引用设计稿链接提取 token，生成草稿（仅输出，暂不写入 UI-KB）。
帮我为 [项目名] [端] 生成设计规范草稿。 Figma 目前尚无规范文件，请： 1. 读取 UI-KB 该项目的 figma-index.md 2. 引用其中设计稿链接，用 Figma MCP 提取色彩/字体/间距/组件规格 3. 生成 design-spec.md 草稿，在此 输出供校验，暂不写入 UI-KB UI-KB 路径：[本地绝对路径]
🤖 AI 读取 figma-index.md → Figma MCP 提取设计 token → 生成 design-spec.md 草稿并输出到对话。
A2
人工校验草稿 逐项检查 AI 输出的设计规范草稿是否准确，有偏差直接告知 Claude Code 修正。
品牌色 HEX 值是否正确
字体族名称和字号是否准确
组件圆角、高度、内边距是否与设计稿一致
间距系统（4px/8px/12px…）是否完整
视觉风格描述是否符合设计意图
A3
在 Figma 中补充完善规范 基于草稿，在 Figma 中新建或整理规范页面，补充以下内容：
各核心组件的多状态截图（default/hover/active/disabled）
色彩 / 字体 Token 展示 Frame
图标 / 插图等视觉资产
组件 Catalog（统一命名，便于 AI 索引）
A4
将最终 Figma 规范地址发给 Claude Code 规范在 Figma 中整理完毕后，将链接发给 Claude Code，触发正式同步到 UI-KB。
设计规范已在 Figma 中整理完毕， 请同步到 UI-KB 和 Skill。 规范文件：[Figma 规范链接] 项目：[项目名] 端：[端/平台] UI-KB 路径：[本地绝对路径]
✓ 已有规范 — 直接同步
B1
准备两类 Figma 链接 分别复制设计稿文件链接和规范文件链接（右键 Frame → Copy link，含 node-id 更精准）。
设计稿文件
figma.com/design/<fileKey>/<文件名>
规范/组件库文件
figma.com/design/<fileKey>/设计规范
B2
发指令给 Claude Code 将两个链接和 UI-KB 路径一起发出，触发规范读取与同步。
帮我将 [项目名] [端] 的 设计规范同步到 UI-KB 和 Skill。 设计稿：[设计稿 Figma 链接] 规范文件：[规范 Figma 链接] UI-KB 路径：[本地绝对路径]
💡 规范内容越完整（含 Token 说明、组件截图），AI 生成的 design-spec.md 越准确，后续 UI 验收和还原精度越高。
⚙
AI 自动处理（无需操作）
🤖
读取 Figma 规范 → 提取色彩 / 字体 / 布局 / 组件规格 → 生成 design-spec.md · figma-index.md · CLAUDE.md → 写入 UI-KB 对应目录 → 创建 Skill → 更新全局配置映射。
2
确认规范内容
AI 输出后，重点核对以下项目，有问题直接告知 AI 修正。
设计师检查
  • 品牌色 HEX 值是否正确
  • 组件尺寸（高度、圆角、间距）是否与设计稿一致
  • 字体族名称是否准确（中文 / 英文 / 等宽）
  • 视觉风格描述是否符合设计意图
  • Figma 文件 Key 和页面 Node ID 是否填写完整
  • 组件 Catalog 是否覆盖项目所有核心组件
3
验证 Skill 可用 可选
在 Claude Code 输入框输入 Skill 名称，确认规范已正确加载。
在 Claude Code 中输入
/[skill-name] # 例如：/justlend-admin # 能看到完整规范内容即表示同步成功
✓ Skill 加载正常 + UI-KB 文件已更新 → 本次规范同步完成。
