## 2. 骨架屏替换规则

### 原则
- 卡片容器结构完全保留（尺寸、圆角、边框、背景模糊）。
- 左上角装饰光晕保留（是背景色块，不是数据）。
- 右侧水印插图：加载中改为 `opacity: 0`，不展示。
- 所有文字和图标替换为骨架条/骨架圆。
- 骨架元素尺寸需贴近真实内容尺寸，避免加载完成后版式跳变。

### 逐层映射

#### 顶部行

| 原始元素 | 骨架替换方案 | 尺寸 |
|---|---|---|
| 标题文字（"Total Supply" 等） | 骨架条 | `width: 96px, height: 14px, radius: 4px` |
| 链图标组（3 个叠放圆形） | 骨架圆 × N | `size: 24px, radius: 12px`，叠放间距同原（-4px offset） |
| 装饰分割线（svg 虚线） | 骨架线 | `height: 1px, opacity: 0.15`，或直接隐藏 |

#### 底部行

| 原始元素 | 骨架替换方案 | 尺寸 |
|---|---|---|
| Token 图标组（2 个叠放圆） | 骨架圆 × 2 | `size: 30px, radius: 15px`，叠放同原（-5.5px offset） |
| 大数字（48px，line-height: 64px） | 骨架条 | `height: 36px, radius: 8px`，宽度见下表 |

#### 大数字骨架宽度（按卡片）

| 卡片 | 原始内容 | 骨架宽度 |
|---|---|---|
| Total Supply | `$413.14M` | `160px` |
| Protocol TVL | `$12,90B` | `140px` |
| APY | `20%` | `80px` |

宽度设定原则：与真实内容视觉宽度保持在 ±10% 以内，避免数据到达后卡片底部出现位移跳变。

## 3. 骨架视觉规格

### 骨架元素颜色

| 场景 | 颜色 | 说明 |
|---|---|---|
| 骨架基底 | `rgba(255, 255, 255, 0.07)` | 深色背景上的低对比占位 |
| shimmer 高光 | `rgba(255, 255, 255, 0.14)` | shimmer 扫过时的最亮值 |

不要使用白色 `#FFFFFF`，也不要使用品牌绿 `#81DEB0`，骨架始终保持中性。

### Shimmer 动效规格

```
类型：   线性渐变横向扫光
方向：   从左到右（90deg）
渐变：   透明 → 高光 → 透明
         rgba(255,255,255,0) → rgba(255,255,255,0.14) → rgba(255,255,255,0)
宽度：   渐变宽度约为骨架元素宽度的 60%
速度：   1.5s / 次，ease-in-out，无限循环
延迟：   同一卡片内的骨架元素统一延迟（不建议每个元素错开，避免混乱）
节奏：   三张卡同时 shimmer，不建议依次触发
```

### Figma 实现方式（Prototype / Smart Animate）

在 Figma 中，shimmer 效果建议用以下方式实现：

1. 在骨架条/骨架圆上叠加一个"扫光层"矩形，填充为横向渐变（透明 → 亮 → 透明）。
2. 用 Smart Animate 让扫光层从 `left: -100%` 移动到 `left: 100%`，持续 1.5s。
3. 勾选 Prototype → After Delay 0ms → 自触发循环。

若是静态交付，只需展示"骨架静态态"即可，不强制要求在 Figma 中实现动效。

## 5. 状态切换规则

```
请求发出
  ↓
骨架态（shimmer 持续）
  ↓
数据返回
  ↓
淡入替换（fade-in, ~200ms）← 数字和图标直接淡入，不做位移
  ↓
正常态
```

- 不允许：数据返回后数字从 `0` 跳变到真实值。
- 不允许：骨架消失后有版式重排（骨架尺寸必须与真实内容近似）。
- 建议：淡入时长 200ms，够短感觉不到延迟，够长不会硬闪。

## 6. Figma 层命名建议

在 UI Kit 内新建 Component 时建议命名：

```
DataCard / Skeleton          ← 骨架态组件
DataCard / Default           ← 正常态（原设计）
DataCard / Error             ← 后续补充
```

骨架卡内层级：

```
DataCard / Skeleton
├── .bg-blur（glassmorphism，与正常态共用）
├── .glow-top-left（装饰光晕，与正常态共用）
├── .watermark（设为 opacity: 0）
└── .content
    ├── .row-header
    │   ├── .skeleton-label（96px 条）
    │   ├── .skeleton-icon-group（叠放圆）
    │   └── .skeleton-divider（可选）
    └── .row-value
        ├── .skeleton-token-group（可选，仅 Card01）
        └── .skeleton-number（宽度各卡不同）
```

| 优先级 | 任务 |
