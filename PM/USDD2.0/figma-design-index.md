## Figma MCP — 设计稿到代码

开发可通过 **Figma MCP** 让 Claude Code 直接读取本索引中的 Figma 设计稿，获取布局、组件、Token 和样式信息，自动生成高还原度的前端代码（HTML/CSS/React），减少手工还原偏差和走查成本。

使用方式：
```
> "请读取 Figma 设计稿 [Figma URL]，生成对应的前端代码"
```
