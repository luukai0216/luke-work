对照 tronlink-v4.20.0-CLAUDE.md，逐项检查：

【色彩】
- 是否存在裸色值（非 CSS token）？
- 是否出现了规范外的颜色？

【字体】
- 字号是否全部来自字阶规范（10/11/12/14/16/20/32px）？

【触控】
- 所有可交互元素高度是否 ≥ 44px？

【层级】
