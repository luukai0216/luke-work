# Prompt：竞品分析

## 使用场景

需要对标竞品功能、了解竞品动态时使用。分快速对标和深度对标两种模式。

## 快速对标（15-30 分钟）

```
请帮我快速对标 [竞品名称] 的 [功能模块]。

先读取我们的基线 PRD：
- USDD2.0/modules/[对应模块].md

请对比以下维度：
1. 功能覆盖：他们有什么我们没有？我们有什么他们没有？
2. 交互差异：同样的功能，交互方式有什么不同？
3. 亮点：有什么值得借鉴的设计？

输出功能对比矩阵表格。
如果可以搜索到竞品信息，请附上信息来源。
```

## 深度对标（2-4 小时）

```
请帮我做 [竞品名称] 的深度竞品分析。

先读取：
- research/competitive/landscape.md（现有竞品全景图）
- shared/product-overview.md（我们的产品定位）

请从以下维度全面分析：
1. 产品定位与目标用户对比
2. 核心功能矩阵对比
3. 用户体验走查（如有截图/可访问产品）
4. 商业模式对比
5. 技术路线对比（公开信息）
6. SWOT 分析
7. 可借鉴的点 + 我们的差异化机会

报告保存到 research/competitive/[竞品名]-deep-analysis-[日期].md
同步更新 research/competitive/landscape.md
```

## 注意事项

- AI 的竞品信息可能不是最新的，需人工验证关键数据
- 建议 PM 亲自体验竞品产品，AI 搜索的信息作为补充
- 不要照搬竞品方案，必须说明为什么适合我们的场景
