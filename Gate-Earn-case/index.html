UI / UX CASE STUDY

Earn Homepage · 2026

Gate-UI笔试题

Gate Earn 理财首页优化。重新组织入口与产品信息，让用户更快找到方向。

DESIGN BY LUKE

01 / 项目目标

产品很多，用户需要的是判断依据。

在保留现有业务的前提下，重新梳理理财首页层级。让产品更早出现，也让收益、期限和风险在选择时被看见。

14项业务保留
04个浏览分类
03个精选位置

02 / 问题分析

信息不少，路径却不够清楚。

01

入口分散

快捷入口、产品 Tab 与重复跳转并存，用户要先理解业务名称，才能开始找产品。

02

重点重复

同一收益数字出现在多处，推荐位和标签也在争夺注意力，页面缺少明确主次。

03

难以比较

不同收益口径并列，期限、参与条件与本金风险却不总在数字旁边。

03 / 页面优化

从入口堆叠，到按类型浏览。

理财首页保留资产概览，将内容收进清晰的浏览路径。用户不必记住 14 个业务名，也能看到适合自己的产品。

01
入口归类赚币、稳定币、质押、进阶策略，覆盖现有业务。
02
精选收敛一张活动主卡、两张规则推荐卡，主次更明确。
03
信息归位列表承担比较；标签收为活动、收益、资格三类。

04 / 分类呈现

不同产品，展示不同的决策信息。

分类保持一致的页面骨架，内容则跟随用户在意的问题变化。

01 / 04

赚币

收益、期限与参与条件放在同一视线里。

02 / 04

稳定币

按币种浏览，直接对照参考年化。

03 / 04

质押

先筛选持有币种，再比较收益。

04 / 04

进阶策略

让收益区间与产品条件一起出现。

05 / 设计总结

让理财首页更像一张清楚的产品地图。

这次优化聚焦信息组织与呈现：减少重复入口，明确精选重点，把影响选择的条件放回产品旁边。方案效果仍需通过真实使用数据验证。
