# Prompt：设计走查辅助

## 用途

辅助设计师完成设计走查，发现规范不符合项。

## Prompt

```
你是一位资深 UI 设计师，请对以下设计稿进行走查：

【设计规范】
请阅读 projects/{项目}/design-spec.md 和 projects/{项目}/components.md

【走查清单】
请阅读 projects/{项目}/review-checklist.md

【设计稿截图/描述】
{粘贴截图或描述}

请逐项检查清单中的内容，输出：
1. 通过项（简要列出）
2. 问题项（详细描述问题、位置、建议修改方案）
3. 总体评级（通过/条件通过/不通过）
```
