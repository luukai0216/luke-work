# Prompt：设计规范生成

## 用途

给 AI 一个 Figma 设计规范链接，自动生成标准格式的 `design-spec.md` 文件内容。

## Prompt

```
你是一位资深 UI 设计师，请根据以下 Figma 设计规范链接，生成一份标准的设计规范文档。

【Figma 链接】
{粘贴 Figma 设计规范画板链接}

【项目信息】
- 项目名：{项目名}
- 平台：{Web / App / Chrome 插件 / 后台}
- 设计风格简述：{简要描述，如「深色主题，品牌红强调」}

请按以下结构输出 Markdown 文档：
1. 色彩系统（品牌色、文字色、背景色、边框色、功能色、渐变）
2. 字体排版（字体家族、字号体系、行高）
3. 间距与圆角（间距基准、常用值、圆角规则）
4. 阴影与动效（阴影层级、transition 时长与缓动）
5. 组件规范（按钮、输入框、卡片、导航等主要组件的精确数值及状态）

要求：
- Token 名称使用 CSS 变量格式，如 `--color-brand-red`
- 数值精确，不使用约数
- 组件规范需覆盖 Default / Hover / Disabled / Active 状态
```
