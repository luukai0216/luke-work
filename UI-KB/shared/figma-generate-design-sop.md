# Claude Code → Figma 设计生成 SOP

> 最后更新：2026-04-02
> 适用范围：所有项目，适用于使用 Claude Code 在 Figma 中生成设计初稿的场景

---

## 流程总览

```
Figma → Copy 设计规范链接
  → Claude Code 生成 Skill Markdown
  → 创建 Skill → 重启 Claude Code
  → /规范名称 激活规范环境
  → 输入页面生成任务（含约束语句）
  → Figma Draft 获取页面 → 人工细化
```

---

## 六步 SOP

### Step 1｜提取设计规范来源（Figma）

1. 打开已有**「设计规范画板（Design System / UI Kit）」**
2. 选中目标规范区域（Frame / Section）
3. 右键 → `Copy link to selection`

**输出：** 可被 AI 解析的设计规范引用链接

---

### Step 2｜生成 Design Skill（Claude Code）

粘贴 Figma 规范链接，输入以下指令：

```
根据该 Figma 设计规范链接，生成一份 Design Skill Markdown 文件，
用于约束 UI 生成时的设计规范使用
```

**输出：** 一份结构化的 Design Skill（Markdown 格式）

---

### Step 3｜加载 Skill（Terminal）

1. 在本地保存 Skill Markdown 文件（路径：`~/.claude/skills/`）
2. 退出当前 Claude Code 终端
3. 重新启动 Claude Code

> Skill 需重启后才会生效，不重启则无法被调用。

---

### Step 4｜调用设计规范（Skill 激活）

```
/规范名称
```

示例：

```
/design-system-web
```

**输出：** 当前对话进入**「设计规范约束环境」**，后续生成遵循该规范

---

### Step 5｜输入页面生成任务（核心步骤）

#### 方式 A：新建 Figma 文件（默认生成至 Draft）

指令需包含：

- 新建一个 Figma 文件
- 指定平台：`Web` / `Mobile`
- 指定页面宽度
- 描述页面内容结构
- 提供原型图链接（如有）
- 约束语句：**「遵从设计规范，不要自由发挥」**

#### 方式 B：基于已有 Figma 文件

指令需包含：

- 提供已有 Figma 文件链接
- 指定生成页面位置 / 新建页面
- 描述页面内容结构
- 提供原型图链接（如有）
- 约束语句：**「遵从设计规范，不要自由发挥」**

**输出：** Claude Code 自动生成页面结构，页面同步出现在 **Figma Draft** 中

---

### Step 6｜结果获取与设计细化（Figma）

在 Figma Draft 中找到 AI 生成的页面，进行以下细化：

| 细化项 | 说明 |
|--------|------|
| 视觉层优化 | 颜色 / 层级调整 |
| 排版优化与交互设计 | 间距、对齐、交互状态补全 |
| 组件替换 / 标准化 | 替换为设计系统中的标准组件 |
| 视觉元素与 icon 绘制 | KV、插图、图标等需手动补充 |

---

## AI 能做 / 不能做

| 能做 | 不能做（需人工） |
|------|------------------|
| 初稿搭建（文案 + 布局结构） | 交互设计 |
| 遵循规范色值填充 | KV / 插图 / 图片 |
| 基础排版（简单布局） | 视觉创意与风格调性 |
| 组件实例放置 | 精细的视觉层次与动效 |

> AI 生成的排版**较为模板化**，初始产出**无交互设计**，也**没有 KV / 图片资产**。细化阶段由设计师主导。

## 提效参考

| 阶段 | 传统模式耗时占比 | Claude Code 介入后 |
|------|-----------------|-------------------|
| 初稿建立 | 100% | ~10% |
| 颜色规范填充 | 100% | ~15% |
| 基础排版 | 100% | ~20% |
| **综合初稿阶段** | 100% | **至少提升 60%+** |

## 关键术语

| 术语 | 说明 |
|------|------|
| Design Skill | 从 Figma 设计规范生成的 Markdown 文件，用于约束 AI 生成 |
| 设计规范约束环境 | 激活 Skill 后 Claude Code 所处的上下文状态 |
| Figma Draft | AI 生成页面的默认落地位置 |
| Copy link to selection | Figma 中复制选中节点链接的操作 |
| 约束语句 | 「遵从设计规范，不要自由发挥」，防止 AI 自由发挥偏离规范 |
