# 资产交付规范

> 最后更新：2026-04-02
> 适用范围：所有项目，设计师向开发交付图片、图标、动效等资产时遵循

---

## 图片格式选择

| 场景 | 推荐格式 | 说明 |
| --- | --- | --- |
| 照片 / 复杂背景图 | WebP | 体积最小，优先使用；需提供 JPG 降级备用 |
| 透明背景图 | WebP（含 alpha）/ PNG | 优先 WebP，不支持时用 PNG |
| 纯色图标 | SVG | 可缩放，支持换色 |
| 多色图标 / 插画 | SVG | 导出前在 Figma 合并图层，减少节点数 |
| 动图 / Lottie | JSON（Lottie）/ WebM 序列 | 复杂动画用 Lottie，简单循环用 WebM |
| 3D 渲染图 / KV | WebP + PNG 备用 | 不使用 JPG，避免压缩失真 |

---

## 切图尺寸

### Web

- 提供 `2x` 即可，开发使用 `srcset` 处理高清屏
- Banner / Hero 图需额外提供移动端裁剪版本

### App（iOS / Android）

| 倍率 | 后缀 | 说明 |
| --- | --- | --- |
| 1x | 无 | 基础尺寸 |
| 2x | `@2x` | Retina |
| 3x | `@3x` | iPhone Pro / 高端 Android |

### Chrome 插件

- 提供 `1x` 和 `2x` 两套

## 文件命名规范

格式：`{项目}-{模块}-{描述}-{尺寸/倍率}.{格式}`

```
tron-home-hero-bg.webp
tron-home-hero-bg@2x.webp
justlend-icon-supply.svg
tronlink-banner-wallet-375.webp
```

规则：
- 全小写，单词间用 `-` 连接
- 不使用中文、空格、特殊字符
- 尺寸写实际像素宽度，如 `-375`、`-1440`

---

## SVG 导出规范

- Figma 导出前：合并同色图层，去除多余蒙版
- 不内嵌 `<style>` 标签，颜色用 `fill` 属性（方便开发用 CSS 覆盖）
- 图标尺寸统一为 24×24px（小图标）或 48×48px（展示图标）
- 删除空 `<g>` 标签和注释节点

---

## Lottie 动画交付

- 导出为 `.json` 格式
- 压缩前确认：无遗漏图层、无外部字体依赖
- 附上设计稿截图（首帧 + 末帧）供开发对照
- 注明循环次数（loop / 播放 N 次）和触发时机

## 交付清单

每次交付资产时，在 Figma 评论或飞书消息中附上：

- [ ] 资产文件（命名规范）
- [ ] 格式说明（哪些是 WebP / SVG / Lottie）
- [ ] 多倍图是否齐全
- [ ] 特殊使用说明（如圆角裁剪、白色背景限制等）
