# TronLink — 项目总览

## 品牌概览

TronLink 是 TRON 生态的官方多平台钱包产品，覆盖移动 App 和浏览器扩展两个端。

## 子端列表

| 子端 | 路径 | 说明 |
| --- | --- | --- |
| App | `app/` | iOS / Android 移动端钱包应用 |
| Chrome 插件 | `chrome/` | Chrome 浏览器扩展钱包 |

## 品牌一致性要求

- 各端共用 TronLink 品牌 Logo 和主色调（填写后统一）
- 不同端的交互模式和布局规范独立维护

## AI 使用规则

- 明确指定端之前，先询问目标端（app / chrome）
- 再读对应子目录下的 `CLAUDE.md`
