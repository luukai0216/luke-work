## 如何使用本 Catalog

每个组件条目包含：
- **Node ID**：Figma 中的唯一标识，用于 `figma.getNodeById()` 或插件调用

- **使用场景**：什么时候用哪个变体

## 附：组件选择决策树

```
需要用户交互？
├── 触发操作 → Button
│   ├── 主要 CTA → 填充按钮
│   ├── 次要操作 → 描边按钮
│   ├── 低优先级 → 文字按钮
│   └── 链/网络切换 → Button/切换
├── 输入内容 → Input / 搜索框
│   ├── 关键词过滤 → 搜索框
│   └── 表单填写 → 输入框（选合适变体）
└── 确认操作 → Modal
    ├── 简单确认 → 400×254
    ├── 带表单 → 400×395 或 600×无tab
    └── 成功/失败反馈 → 对应状态变体

展示数据？
├── 版本标记 → V2 Badge (142:360)
├── 网络标记 → 主网 Badge (142:359)
├── 进度展示 → 进度条1/2
├── 列表数据 → Table（参见 design-spec.md）
└── 分页 → 分页组件

页面框架？
├── 侧边栏 → 侧边栏 (197:1552)
└── 多步骤流程 → Steps（手动实现）
```
