## [DDR-001] 采用纯黑背景 + 品牌红高光的视觉基调

- **日期**：V3.5.0
- **背景**：TRON 官网需要传达区块链科技感与去中心化的未来感，与主流互联网产品形成差异化
- **方案选项**：
  - 方案 A：纯黑（`#000000`）背景 + 品牌红（`#D01919`）高光
  - 方案 B：深灰背景 + 蓝紫渐变（常见 Web3 风格）
- **结论**：选择方案 A
- **原因**：黑红对比更强烈，与 TRON 六边形 Logo 的品牌红形成强统一性；纯黑背景衬托 3D 视觉资产效果更佳
- **影响范围**：所有页面背景、卡片、Header、Footer

## [DDR-002] 按钮采用全圆角 Pill 形态

- **日期**：V3.5.0
- **背景**：按钮风格影响整站调性
- **方案选项**：
  - 方案 A：圆角 100px（Pill，全圆角）
  - 方案 B：圆角 8px（常规圆角）
  - 方案 C：直角
- **结论**：选择方案 A
- **原因**：Pill 形态在深色背景下具有更强的现代感与科技感，与 Tab/Filter 组件风格统一
- **影响范围**：Primary Button、Secondary Button、Dropdown Button、Tab/Filter

## [DDR-003] Error 色复用品牌红 `#E5282A`

- **日期**：V3.5.0
- **背景**：功能色体系设计时，Error 状态需要一个醒目的颜色
- **方案选项**：
  - 方案 A：复用品牌红 hover 色 `#E5282A` 作为 Error 色
  - 方案 B：使用独立的纯红色（如 `#FF3333`）
- **结论**：选择方案 A
- **原因**：在纯黑背景下，`#E5282A` 与品牌红 `#D01919` 有足够区分度，且减少色彩系统复杂度；用户对红色本身已有「警告」认知，不会造成混淆
- **影响范围**：Input error 状态、Toast error、表单校验

## [DDR-004] Header 使用磨砂玻璃效果而非不透明背景

- **日期**：V3.5.0
- **背景**：Hero 区域背景复杂（3D 视觉资产 + 光晕），Header 需要与其融合
- **方案选项**：
  - 方案 A：`rgba(0,0,0,0.9)` + `backdrop-filter: blur(20px)`（磨砂玻璃）
  - 方案 B：`#000000` 纯黑不透明背景
- **结论**：选择方案 A
- **原因**：半透明磨砂效果使 Header 与 Hero 区域自然衔接，避免割裂感；同时在滚动后加 `1px solid #1A1A1A` 底部边框增强层次区分
- **影响范围**：全局 Header

## [DDR-005] Footer 底部条使用品牌红实底

- **日期**：V3.5.0

- **方案选项**：

## [DDR-006] 卡片 hover 状态使用品牌红边框 + 上移

- **日期**：V3.5.0
- **背景**：深色背景上的卡片需要有清晰的 hover 反馈
- **方案选项**：
  - 方案 A：边框变为 `#D01919` + `translateY(-4px)`
  - 方案 B：背景色加亮
  - 方案 C：仅加投影
- **结论**：选择方案 A
- **原因**：红色边框与品牌色统一，上移动效增加交互层次感；背景加亮在纯黑背景上效果不明显
- **影响范围**：所有卡片组件（Card）

## [DDR-007] 展示标题字体使用 Zero World

- **日期**：V3.5.0
- **背景**：Hero 区域和大型数据展示需要专属展示字体
- **方案选项**：
  - 方案 A：Zero World（定制/品牌字体）
  - 方案 B：Inter（通用英文字体）
- **结论**：选择方案 A（展示用途），Inter 用于正文
- **原因**：Zero World 具有强烈的科技未来感，符合 TRON 品牌调性；Inter 可读性更高，适合正文与数据说明
- **影响范围**：Display XL / Display L 级标题、Hero 文案、统计大数字
