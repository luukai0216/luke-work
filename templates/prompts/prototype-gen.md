# Prompt：生成 HTML 原型

## 使用场景

PRD 定稿后，需要生成可交互的 HTML 原型。

## Prompt 模板

```
请根据 PRD 生成可交互的 HTML 原型。

先读取：
- USDD2.0/iterations/v{x.y.z}/prd-{name}.md（需求定义）
- USDD2.0/design.md（设计规范：颜色 token、字体、间距、圆角）
- USDD2.0/prototype/screenshots/（现有界面，在此基础上迭代）

要求：
1. 手机端原型使用 375px 宽度，用 .phone-shell 包裹
2. 必须覆盖以下状态，每个状态单独一屏：
   - 正常态（有数据）
   - 空态（无数据）
   - 加载态
   - 错误态
3. 颜色全部使用 design.md 中的 token，不使用裸色值
4. 可交互元素触控尺寸 ≥44px
5. 弹窗、底部抽屉等浮层单独出图，不藏在交互里
6. 图标使用 SVG，从源码中提取真实图标

生成后请自检：
- statusbar / navbar / 内容区 / tabbar 结构完整
- 左右 margin 符合规范
- 字号在规范定义的字阶范围内
```

## 注意事项

- 已有产品迭代：先做像素级还原，再在此基础上做变体
- 从 0 到 1：可以从零生成，但必须遵循设计规范
- 修改指令要具体：「把卡片圆角从 8px 改为 12px」而非「帮我改好看点」
