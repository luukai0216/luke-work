# Prompt：生成新功能 PRD

## 使用场景

需要为一个新功能生成 PRD 初稿时使用。

## Prompt 模板

```
请帮我生成 [功能名称] 的 PRD。

先读取以下文件建立上下文：
- shared/product-overview.md（产品全景）
- shared/glossary.md（术语一致性）
- shared/api-reference.md（现有接口能力）
- USDD2.0/modules/[相关模块].md（现有基线 PRD）
- USDD2.0/design.md（设计规范）

功能背景：
[描述为什么要做这个功能，有什么数据/反馈支撑]

核心需求：
[描述用户想要做什么，达成什么目标]

约束：
[时间/技术/资源约束]

请严格按照 templates/prd-template.md 的 12 章节结构输出。
异常场景要写清具体的错误码和文案，不要用模糊描述。
不确定的地方标注「⚠️ 待确认」。
给出方案选项时提供 2-3 个对比，等我选择。
```

## 注意事项

- 生成后必须人工审阅每一章节
- 重点检查：数据是否编造、接口是否存在、业务规则是否准确
- 建议先生成骨架确认方向，再逐章填充
