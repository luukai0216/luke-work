# Prompt：逆向还原基线 PRD

## 使用场景

已上线产品缺少文档，需要从现有产品/代码逆向生成基线 PRD。

## Prompt 模板

```
请帮我逆向还原 [模块名称] 的基线 PRD。

请先进入 Plan Mode，读取以下内容：
- USDD2.0/prototype/screenshots/ 中与该模块相关的截图
- shared/glossary.md（使用标准术语）

如果可以访问源代码，请通过 Plan Mode 分析：
- 页面组件结构
- 路由和导航逻辑
- 状态管理和数据流
- API 调用

注意：
- 这是基线 PRD，描述「现在是什么样」，不是「要做什么」
- 严格按照 templates/prd-template.md 结构输出
- 不确定的功能逻辑标注「⚠️ 待确认：需与开发确认」
- 不编造不存在的功能
- 对于无法从截图/代码确认的业务规则，留空并标注
```

## 注意事项

- 逆向 PRD 必须与实际产品逐条校验
- 建议按模块分批进行，不要一次性逆向整个产品
- 逆向完成后请开发同事 review 技术相关描述的准确性
