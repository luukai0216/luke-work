① CR 规范文档

i18n key
data.overview.kpi.cr
页面
Data / Overview 顶部
刷新
每分钟
数据源
Vat.urns + Spot.pip + PSM.gemBalance + SA NAV

计算公式

CR = [Σ(Vault.ink × pip) + Σ(PSM 储备 USD) + SA NAV] ÷ Σ(USDD totalSupply − 桥锁仓)

子状态联动

  • CR ≥ 200% → Healthy 绿色徽章
  • 150% ≤ CR < 200% → Stable 蓝色徽章
  • 110% ≤ CR < 150% → Warning 黄色徽章 + 风控群告警
  • CR < 110% → Critical 红色徽章 + On-Call 紧急告警

陷阱 / 注意

  • 价格用 OSM（带 1h hop），不是 median price，tooltip 必须明示
  • 跨链 USDD 必须减去桥锁仓避免重复计入
  • SA NAV 只计 realized + 持仓本金，不计 unrealized PnL

② 抵押品结构占比规范

i18n key
data.overview.collateral_composition
页面
Data / Overview — CR 卡片下方
刷新
每分钟（与 CR 同步）
数据源
Vat.ilks.Art × pip / PSM.gemBalance / SA NAV

计算公式

对每个 asset 类别 c：
占比[c] = Σ(c 类资产 USD 价值) / Total Collateral USD
资产类别归并：
• TRX 系 = TRX-A/B/C + sTRX-A
• WBTC 系 = WBTC-A/B
• 稳定币储备 = 各链 PSM 持有的 USDT + USDC
• Smart Allocator = SA 全部 strategy NAV
• 其他 = 上述外的所有 ilk

三种视图切换

  • 按资产类型（默认）：donut 5 段，最容易识别"过度依赖谁"
  • 按链：donut 4 段（TRON / ETH / BSC / BTTC），看链发行结构
  • 按 ilk：donut N 段，给研究员细粒度数据

子状态联动 / 告警

  • 单一资产占比 ≥ 40% → 该段闪烁 warning 边框 + KPI 卡红色提示
  • 单一资产占比 ≥ 60% → 风控群告警
  • 稳定币储备占比 < 15% → 锚定弹性预警（PSM 缓冲不足）
  • Donut 段点击 → 下钻到该类的详细组成（TRX 系 → TRX-A/B/C/sTRX-A 拆分）
  • 历史曲线与 donut 联动：donut 选中某段，曲线对应高亮

陷阱 / 注意

  • SA 与 PSM 概念重叠：PSM 持有的 USDT 由 SA 投资部分 → 避免重复计入。建议口径：PSM 余额仅算"未投资 idle"部分，已投资部分归 SA
  • sTRX 应归入"TRX 系"而非独立类，因价格强相关（> 0.95）
  • 稳定币 PSM 储备按面值（1:1 USD）计，不按预言机价 — 避免 USDT 微脱锚污染数据
  • 跨链同名资产合并：TRON-WBTC 与 ETH-WBTC 都归 "WBTC 系"

② PSM 净流量规范

i18n key
data.overview.kpi.psm_net_flow
页面
Data / Overview + Data / Chain
数据源
DssPsm.SellGem + DssPsm.BuyGem 事件
PSM 实例
TRON PSM-USDT-A / ETH PSM-USDT / BSC PSM-USDT

计算公式

Net Flow = Σ_chain Σ_psm (SellGem value − BuyGem value) over window
方向解读：正值 = Mint 主导（USDD 需求增长） / 负值 = Redeem 主导（赎回压力）

子状态联动

  • 24h 净流量正负切换 → KPI 数字颜色切换
  • 柱状图正值用 brand 绿色系，负值用 warning 橙色
  • 单链单日净流出 > 50M → 风控群告警 + 在该链 KPI 卡显示 ⚠️
  • Tab 切换 24h/7d/30d → 同步更新主图时间窗与表格

陷阱 / 注意

  • USDT decimal = 6, USDC = 6, DAI = 18 — 跨链汇总必须归一化
  • 桥转出不算 PSM 净流量
  • SellGem value 是否含 fee 需链上确认

③ 仓位健康度分布规范

i18n key
data.chain.health_distribution
页面
Data / Chain + Collateral Detail
数据源
遍历 Vat.urns + Spot.mat + 实时 oracle
前置依赖
需先建 CDP urn indexer

计算公式

health = (urn.ink × pip_price) / (urn.art × rate × Spot.ilks[i].mat)
说明：health = 1 即将被清算；< 1 已可被 Keeper 触发

分桶规则

  • 🔴 health < 1.05 — danger，红色
  • 🟠 1.05 ≤ health < 1.20 — warning，橙色
  • 🟡 1.20 ≤ health < 1.50 — info，青色
  • 🟢 health ≥ 1.50 — success，绿色

子状态联动

  • 切换"按债务额 / 按 Vault 数"时主图重排，颜色不变
  • 点击桶 → 展开 Top 20 CDP 表格（urn 地址、抵押品、债务、health）
  • 🔴 桶债务占比 > 10% → 风控群告警；> 20% → 紧急
  • PSM Vault 不参与该指标（1:1 锚定无清算价）

陷阱 / 注意

  • 多 ilk LR 不同（TRX-A 175% / TRX-B 130%），必须先按 ilk 计算再聚合
  • sTRX 价格 = TRX × staking 兑换率，需用复合预言机

④ Debt at Risk 规范

i18n key
data.overview.debt_at_risk
页面
Overview + Collateral Detail
数据源
复用 ③ 健康度遍历结果 + 价格冲击模拟

计算公式

对每个冲击 s ∈ {-5%, -10%, -20%, -30%}：
DaR[s] = Σ {urn.art × rate | (urn.ink × pip × (1+s)) / (urn.art × rate) < mat}

冲击模式

  • 全市场冲击：所有非稳定币抵押品同跌 — Overview 默认
  • 单资产冲击：仅指定资产下跌 — Collateral Detail 默认
  • 关联冲击：TRX → sTRX 联动跌 — 高级模式

子状态联动

  • -20% DaR > 总债务 30% → 风控介入
  • -30% DaR > 总债务 50% → 系统性风险告警
  • Tab 切换冲击模式 → 主曲线重算，不切场景 KPI 卡数字

陷阱 / 注意

  • 稳定币 PSM 不在 DaR 范畴（peg risk 是另一类）
  • DaR 是"进入清算的债务"，不等于"坏账"。坏账 = DaR × (1 − 拍卖回收率)
  • 预言机 OSM hop 延迟需在 tooltip 明示

⑤ 实时 Revenue 规范

i18n key
treasury.realtime
页面
USDD Treasury 顶部
数据源
链上事件 indexer + 链下国库账本

Revenue 公式

Revenue = 稳定费 (jug.drip 切片) + PSM fee + 清算 chop 分润 + SA realized yield
Earnings = Revenue − Keeper tip/chip − sUSDD 利息支出
Net Profit = Earnings − Expenses（链下国库支出）

子状态联动

  • Net Profit > 0 → 绿色 + "盈利" badge；< 0 → 红色 + "亏损" badge
  • Tab 切换 7D/30D/90D → 主图时间窗 + 全局 Time Range Picker 联动
  • Revenue stacked bar 鼠标 hover → 显示具体数值
  • 来源拆解表行 → 可点击下钻 Accounting Events 明细

陷阱 / 注意

  • 稳定费按 jug.drip time slice 摊平，不能一次性显示突增
  • SA earnings 只计 realized，unrealized 在 SA 页单独展示
  • Expenses 链下数据有 T+1 延迟，tooltip 标注
  • 跨链 4 链分别 indexer + 全局汇总
